# Система записи к врачу

Система позволяет пациенту самому записаться к врачу через сайт в любое время, без звонка в регистратуру.
Клиника видит все записи в одном месте, а напоминания уменьшают число пропущенных приёмов.

Учебный проект по дисциплине «Программная инженерия». Код приложения не разрабатывается,
в репозитории хранится проектная документация.

## Пользователи

- **Пациент** записывается, отменяет и переносит запись, смотрит свои посещения.
- **Врач** видит своё расписание и пациентов, отмечает приём или неявку.
- **Администратор** ведёт врачей и расписания, записывает пациентов вручную, смотрит статистику.

## Основные возможности

- Регистрация и вход по email и паролю.
- Запись на свободное время выбранного врача без двойной записи на одно время.
- Отмена и перенос записи до начала приёма.
- Письмо с подтверждением и напоминание за 24 часа.
- Расписание врача и отметка «приём состоялся» или «неявка».
- Расписания врачей, ручная запись и отмена с причиной у администратора.
- Статистика загрузки врачей и неявок за период.
