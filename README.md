# Система записи к врачу

Учебный проект по дисциплине «Программная инженерия». Система позволяет пациенту выбрать врача и свободное время, создать, отменить или перенести запись на приём. Врач видит расписание, администратор управляет работой клиники.

## Основные возможности

- Регистрация и вход пациента.
- Выбор специальности, врача и свободного времени.
- Создание, отмена и перенос записи на приём.
- Подтверждения и напоминания.
- Расписание врача и отметки о посещении.
- Управление расписаниями, ручная запись и статистика администратора.

## Документация

Материалы проекта находятся в папке `docs`. Код приложения в рамках этих заданий не разрабатывается.
